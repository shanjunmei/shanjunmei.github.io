# 个人介绍页

> 一组自包含、单文件的个人介绍页，面向 shanjunmei —— Go 后端架构师、开源维护者（dig / digen）、AI Agent 实践者。

**[English](README.md)**

---

## 1. 项目概览

三份面向不同受众的独立 HTML 页面，外加一份独立简历。每个页面都是单文件自包含（内联 CSS + JS + i18n），可直接用 `file://` 打开或部署到任意静态托管。无需构建、无共享依赖、无外部运行时——每个文件都能独立发布。

## 2. 各版本栏目

- **通用版** —— 关于 · 项目 · 理念 · 技术栈 · 联系
- **求职版** —— 关于 · 项目 · 理念 · **能力** · 技术栈 · 联系
- **获客版** —— 服务 · 案例 · 合作方式 · 优势 · 联系

每个页面都内置「英文 / 中文」语言切换与「浅色 / 深色」主题切换。内容切换完全由前端通过 `data-i18n` 属性完成。

## 3. 功能特性

- **移动端导航** —— 在 ≤ 640px 屏幕上以汉堡菜单替代桌面链接栏；支持点击展开/收起、点击外部关闭、Esc 关闭，并带 `aria-expanded` / `aria-controls`。
- **联系方式闭环** —— 获客版原本的占位邮箱已替换为真实 `mailto:shanjunmei@qq.com` 链接；三页联系区均展示该邮箱。
- **社交 / SEO 元数据** —— 每个 `<head>` 均补充了 Open Graph、Twitter Card 与 `JSON-LD Person` 结构化数据，分享链接可获得富预览。
- **Safari 兼容** —— 导航毛玻璃在 `backdrop-filter` 之外补充了 `-webkit-backdrop-filter` 前缀。
- **无障碍** —— 首个可聚焦元素为「跳到主内容」skip-link；图标 `aria-hidden`、键盘可达性、`prefers-reduced-motion` 均已覆盖。
- **统一版式** —— 区段间距由单一 `--gap-section` 变量控制，便于一处微调整体节奏。

## 4. 预览与发布

1. 直接用浏览器打开任意 `.html` 文件（双击或使用 `file://` 路径）即可，无需服务器。
2. 发布：将单文件上传至任意静态托管（GitHub Pages、Netlify、对象存储等）。每个文件均完全自包含。

## 5. 说明与约定

- **坐标** —— 三页坐标统一为 `深圳 · China` / `Shenzhen · China`。
- **字体** —— 字形通过 `miaoda.feishu.cn` 字体 CDN 加载，并保留系统字体兜底与 `display=swap`。为保持单文件独立性，未做字体自托管。
- **邮箱** —— `shanjunmei@qq.com` 为全站统一联系方式。
- **不自动提交** —— 默认改动保持未提交状态，仅在明确要求时才提交。

## 6. 自定义

修改文案：编辑每个文件内的 `i18n` 词典（中文 + 英文），界面文本绑定到 `data-i18n` 键。修改颜色 / 间距：编辑 `<style>` 顶部的 CSS 自定义变量。新增栏目：复制一个 `.section` 块，并登记其导航链接与 i18n 键。
