关于我

我是一名后端架构师，十多年 Java 后端打底，五年来主力转向 Go。长期在做三件事：打磨编译期依赖注入框架 dig 与代码生成器 digen；从零构建 AI Agent 系统 Hermes；把「平台公约」逐条落地成 Ride、huidao、LogiX 等平台的代码与制度。

我偏好的工程方式：选型从原理出发，方案必须可验证，数字必须可追溯。计算密集的事交给 C/C++，编排与控制交给 Go；能编译期解决的绝不留给运行时；能删掉的中间产物绝不保留过渡兼容。

对产品，我坚持「不玩套路，只赚明钱」——明码实价、排序不卖、广告必标、无会员无订阅。每一分钱的去向写进账单，每一次处置的理由摆上桌面。

理念

第一性选型

计算密集交给 C/C++，编排交给 Go；边缘最轻、中心汇聚；部署只认 Linux。不跟风，看本质。

最小可靠

单静态二进制、零运行时反射、进程即用即关。能删的代码不保留，能重建的不过渡兼容。

透明可审计

每一分钱可核对、每一次处置可申诉、每一个结论可复现。数据对不上，就当 bug 修。
